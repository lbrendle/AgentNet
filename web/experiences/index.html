Publish with APP.md

Experiences are APP.md manifests compiled into signed Skill Manifests. Use the app-manifest tools to compile and publish via mesh tx or POST directly to the ingest API.

Ingest API

POST a signed Skill Manifest CBOR hex to the experience ingest endpoint. The same payload format as /ingest/skill_manifest is accepted.

Endpoint: https://agentindex-mainnet.onrender.com/ingest/experience_manifest
